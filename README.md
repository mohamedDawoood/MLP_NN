# Character-Level MLP Language Model 

A from-scratch implementation of a **Character-Level Multi-Layer Perceptron (MLP) Language Model** using PyTorch, inspired by Yoshua Bengio's seminal paper *(A Neural Probabilistic Language Model, 2003)* and Andrej Karpathy's *Makemore* series.

This project demonstrates vector embeddings, context sliding windows, minibatch optimization, learning rate schedules, and text generation byte-by-byte.

---

##  Features & Architecture

* **Context Length (`block_size = 3`):** Uses a sliding window of 3 preceding characters to predict the next character.
* **Character Embeddings:** Maps each character in the vocabulary into a dense 10-dimensional continuous vector space.
* **Neural Network Structure:**
  * **Input Layer:** Flattened embedding vectors ($3 \times 10 = 30$ dimensions).
  * **Hidden Layer:** 200 neurons with a $\tanh$ activation function.
  * **Output Layer:** Softmax distribution over the entire character vocabulary.
* **Dataset Pipeline:** 
  * Deterministic random shuffling with strict **80% Train / 10% Dev / 10% Test** splits.
  * Special start/end token (`.`) handling for word boundary generation.
* **Optimization & Training:**
  * Mini-batch Stochastic Gradient Descent (SGD) with batch size = 32.
  * Cross-Entropy Loss optimization (`F.cross_entropy`).
  * Learning rate scheduling to balance convergence speed and loss stability.

---

##  Results & Performance

| Metric | Score |
| :--- | :--- |
| **Training Loss** | `~1.91` |
| **Validation Loss (Dev)** | `~2.15` |

The narrow gap between Training Loss and Dev Loss demonstrates optimal generalization without memorization or severe overfitting.
